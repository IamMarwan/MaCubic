# Week 14 - AI Document Compliance Review

## Goal
Develop an AI service that reviews construction documents against predefined requirements and highlights missing or inconsistent information.

## Features

- Configurable validation rules
- Document type detection
- Metadata validation
- Mandatory section checking
- Signature verification
- Revision and approval checking
- Compliance scoring
- JSON report generation
- PDF report generation
